# ved·Life — сайт издательства

Статический сайт на [Astro](https://astro.build): каталог книг, страницы книг и читалка с бесплатными первыми главами. Два языка: `/ru/` и `/en/`.

## Что в прототипе

| Страница | Что показывает |
|---|---|
| `/ru/`, `/en/` | Главная: девять дверей (восемь направлений из брендбука и «Игры»), лестница глубины по входу, тизеры читалки и Мастерской |
| `/…/layers/` | Читалка со слоями: источники открыты, иллюстрации, звук и кадры — по подписке или с кодом из бумажной книги. Звук собирается в браузере (Web Audio), файлов нет |
| `/…/studio/` | Мастерская: лестница «задание → мастерская → релиз → резиденция», образцы заданий, форма заявки |
| `/…/membership/` | Подписка: три уровня, матрица «слой × уровень», код бумажной книги |

Условия подписки и Мастерской помечены «прототип» и не утверждены. Данные порталa лежат в `src/lib/portal.ts`.

### Обложки

У каждой книги свой рисунок, найденный в её смысле и собранный только из словаря системы (Поле, Рассеяние, Накопление, Континуум). Генератор — `src/lib/coverart.ts`, поле `cover` у книги в `catalog.ts` задаёт рисунок, поверхность и положение панели с названием. Новая книга — новый рисунок: выберите вид (`field`, `ripple`, `accumulation`, `board`, `truchet`) и число `seed`, рисунок всегда один и тот же при одном `seed`.

## Запуск

```sh
npm install
npm run dev      # http://localhost:4321
npm run build    # статика в dist/
```

## Где что лежит

| Путь | Что это |
|---|---|
| `src/lib/catalog.ts` | Каталог: книги, территории (серии), номера «Живого указателя», число открытых глав, магазины |
| `src/lib/i18n.ts` | Тексты интерфейса на русском и английском |
| `src/content/books/<slug>/<lang>/` | Тексты глав: `index.json` (оглавление) и по файлу на главу |
| `src/styles/tokens.css` | Дизайн-токены из брендбука: цвета, шрифты, линейки |
| `src/components/` | Знак, вордмарк, обложки серий, шапка, подвал |
| `public/brand/` | Логотипы, глифы территорий, паттерны (SVG) |
| `public/fonts/` | Шрифты и их лицензии |

## Как добавить книгу

1. Импортировать текст из Word:
   ```sh
   pip install python-docx
   python3 scripts/import-docx.py путь/к/книге.docx <slug> ru
   ```
   Главы делятся по строкам «Пролог», «Введение», «Глава N. …», «Заключение» (или английским аналогам).
2. Добавить книгу в `BOOKS` в `src/lib/catalog.ts`: номер указателя, территорию, названия, описание, сколько глав открыто (`freeChapters`).

Страницы читалки собираются только для открытых глав, остальные главы видны в оглавлении как «полная версия».

## Шрифты

Пока нет веб-лицензий на Neue Haas Grotesk и Monument Extended с кириллицей, используются бесплатные Inter (заголовки и текст) и Science Gothic (лейблы, ширина 150, жирный). Замена — в `src/styles/tokens.css`.
